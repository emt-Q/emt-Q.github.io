Selected Projects

  1. Limit Order Book Market Making & Statistical Arbitrage

    View code ↗

    Quantitative trading · Python

    An event-driven order book simulator comparing inventory-aware quoting with a naive baseline under identical informed order flow, with a cointegration-based pairs-trading backtest.

    Methods and results

    Price-time priority, reservation-price quoting, position limits, adverse-selection measurement, and rolling OLS hedge ratios.

    The inventory-aware agent reports a session Sharpe of 15.9, versus −13.6 for the naive baseline. This is a controlled simulation using seed 7 and 6,000 ticks, not live trading.

  2. LOB Execution Lab

    View code ↗

    Quantitative trading · Python

    A research backtest of limit-order-book execution on Binance BTCUSDT L2 data, studying when posting limit orders beats taking liquidity once queue position, latency, and adverse selection are modeled.

    Methods and results

    Tick-by-tick book reconstruction, FIFO queue-position fill simulation with symmetric latency, and walk-forward order-flow signals (queue imbalance, microprice, OFI) driving four execution strategies over 200 paired parent orders at 0, 10, 50, and 100 ms.

    On the synthetic stream (seed 7), the signal-driven adaptive strategy reaches a 20-tick markout of +0.20 ticks at zero latency, versus −1.25 for market-taking, but falls to −1.08 at 100 ms. Passive strategies degrade fastest with latency. The reported numbers use synthetic data and a frozen-book assumption, not live trading.

  3. Quant Factor Lab

    View code ↗

    Quantitative research · Python

    A multi-factor pipeline for constructing signals, testing significance, controlling false discoveries, and evaluating long-short portfolios after transaction costs.

    Methods and results

    Nine curated signals are evaluated with IC, Rank-IC, t-tests, and BHY-FDR correction before out-of-sample portfolio evaluation.

    Synthetic validation with planted alpha reports a 7.29 Sharpe. The real-data long-short reference reports 0.83 across 20 mega-cap stocks over 2019–2024, with only 15 out-of-sample rebalances.

  4. Cinder

    Visit website ↗

    Game development · Co-founder · Unity, C#

    A top-down pixel sword game for Windows and macOS, currently in development: up to 5v5 team plant-and-defuse matches, free-for-all brawls, and a resource-and-siege mode, played over UDP.

    Technical details

    Authoritative dedicated-server architecture with a fixed 60 Hz simulation, 30 Hz snapshots, client-side prediction and reconciliation, and interpolated remote players, plus adaptive-skill bots that play as coordinated teams.

    Edit-mode tests cover combat, collision, rounds, and snapshot encoding, and every push builds the Windows and macOS players in CI. The game has not been released yet.

Performance figures are reported in the linked repositories. Simulated and historical results do not represent live trading performance.
